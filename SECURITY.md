# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability**
option in this repository's Security tab. Do not disclose exploit details or
sensitive sample files in public issues. Maintainers will coordinate fixes and
disclosure through the private advisory.

Include the affected version/platform, reproduction steps, impact and the smallest
safe sample you can share. Remove personal data, keys and private URLs. If you
cannot share a sample, describe its structure and how it was created.

The current desktop is a migration preview. Security hardening and release
acceptance are ongoing; it is not a sandbox for hostile files. Native codecs and
operating-system libraries retain their own security risks. Run current builds
and keep your operating system updated.

There is no paid security tier or guaranteed response SLA. Use the latest release;
older preview builds are not a supported security-update channel.
