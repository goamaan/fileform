# Support

Use GitHub issues for reproducible bugs and improvement proposals. Include the
Fileform version, OS/architecture, steps, expected behavior and actual result.
A small generated example is better than a private document. Never post passwords,
license keys, private links or customer data.

Fileform is maintained as an open-source project. Help is voluntary; there is no
purchase, account requirement or guaranteed response time. Check the README and
operation documentation for currently implemented routes and known limitations.

Security reports belong in the private process described in SECURITY.md.
